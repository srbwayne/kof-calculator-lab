# OBS-009 — Constant division by zero passes check and surfaces JVM exception

Category: COMPILER / DIAGNOSTICS / RUNTIME
Status: CONFIRMED

## Source

    main() {
        println(1 / 0)
    }

## Static check

Command:

    kof check division_by_zero.kf

Result:

    checked 1 file(s) ? no errors

Therefore the constant integer division-by-zero expression was not
rejected during the observed static check phase.

## Runtime

Running the same unchanged source produced:

    Exception in thread "main" java.lang.ArithmeticException: / by zero
        at Default.Main.main(division_by_zero.kf:3)

## Observed behavior

- `kof check` accepts the constant expression `1 / 0`;
- division by zero is deferred to runtime;
- runtime exposes the underlying JVM `ArithmeticException`;
- the failure is mapped back to `division_by_zero.kf:3`.

## Positive observation

Source-location mapping is preserved in the runtime exception.

## Potential UX consideration

A Kof-specific runtime diagnostic could potentially provide a more
language-native error experience than exposing the JVM exception
directly.

Alternatively, constant division by zero could potentially be detected
during static analysis.

These are improvement hypotheses, not conclusions about the intended
language semantics.

## Classification

Confirmed observed behavior.

Not yet classified as an upstream defect.
