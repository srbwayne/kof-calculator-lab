# OBS-007 — `kof run --help` is interpreted as source path

Category: CLI / UX
Status: OBSERVED

## Command

    kof.bat run --help

## Result

    file not found: --help

## Interpretation

In the frozen Kof 0.0.7-alpha snapshot, the `run` subcommand interprets
`--help` as the source-file argument rather than displaying
subcommand-level help.

## Impact

A new user cannot discover `run` usage through the conventional:

    kof run --help

pattern.

## Classification

Observed CLI behavior.

Not currently classified as a defect.

## Potential future improvement

Provide subcommand-level help or document the supported command
discovery mechanism.
